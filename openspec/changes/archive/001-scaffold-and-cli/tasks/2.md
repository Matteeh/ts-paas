## Context

Reuse `packageVersion()` from `src/version.ts` for the version. Use commander's `exitOverride()` so it throws `CommanderError` instead of exiting, `configureOutput()` to route its output through `Io` and to replace its leading `error: ` with `paas: `, and `showHelpAfterError()` for usage after a parse error. A `CommanderError` with `exitCode` 0 (help, version) returns 0. With no subcommands registered, commander reports `paas nope` as too many arguments; that is still a usage error.

Tests call `run` in-process with a capturing `Io`. Only the child-process test spawns `process.execPath` with `--import tsx src/cli.ts`. No test reads `dist/`.

## Ports

```ts
// src/output.ts
export interface Io { out(text: string): void; err(text: string): void }
export const processIo: Io; // writes to process.stdout and process.stderr
export function writeOutput<T>(io: Io, value: T, options: { json: boolean }, format: (value: T) => string): void;

// src/errors.ts
export class UsageError extends Error {}

// src/program.ts
export function buildProgram(io?: Io): Command; // a fresh commander program named paas on every call
export function run(argv: readonly string[], io?: Io, program?: Command): Promise<number>; // argv excludes node and script; returns the exit code
```

## Acceptance
- [ ] `run([])`, `run(["--help"])`, and `run(["-h"])` write the same help, starting with `Usage: paas`, to `out`, nothing to `err`, and return 0; a test asserts every command in `buildProgram().commands` has a non-empty single-line description that appears in the help.
- [ ] `run(["--version"])` and `run(["-V"])` write exactly `packageVersion()` and a newline to `out` and return 0.
- [ ] `run(["nope"])` and `run(["--bogus"])` write a first line starting with `paas: ` (the second mentions `--bogus`) and then the usage text to `err`, nothing to `out`, and return 2.
- [ ] A program with an added command whose action throws `new UsageError("bad")` makes `run` write `paas: bad` then the usage text to `err` and return 2; one whose action throws `new Error("boom")` makes `err` exactly `paas: boom\n` and returns 1.
- [ ] `writeOutput` in JSON mode writes exactly `JSON.stringify(value)` and a newline; in human mode it writes `format(value)` and a newline; covered in `tests/output.test.ts`.
- [ ] `src/cli.ts` starts with `#!/usr/bin/env node` and sets `process.exitCode` to `await run(process.argv.slice(2))`.
- [ ] A child-process test runs `src/cli.ts` through `tsx`: `--version` exits 0 with the version on stdout, and `nope` exits 2 with stderr starting `paas: `.
