## Changed

- `src/runtime/socket.ts` (new): `SocketProbe`, `SocketSource`, `ResolvedSocket`, `nodeSocketProbe` and `resolveSocket`. Resolution honours `PAAS_SOCKET`, a `unix://` `DOCKER_HOST` (scheme stripped), then `PODMAN_SOCKET`; an explicit setting is final and a missing one throws `RuntimeUnavailableError` `cannot reach container engine at <path>: socket not found`. Otherwise it probes `/var/run/docker.sock`, `<homedir>/.docker/run/docker.sock`, then `$XDG_RUNTIME_DIR/podman/podman.sock` (or `/run/user/<uid>/podman/podman.sock` when unset/empty), and throws the contracted "no container engine socket found" message listing all three paths. Empty variables count as unset, and a non-`unix://` `DOCKER_HOST` is ignored. No dockerode, no network.
- `src/runtime/docker-logs.ts` (new): `demuxDockerLogs(data, {tty})` splits 8-byte-header frames (byte 0 stream, bytes 4-7 big-endian length), joins lines split across frames of one stream, emits one entry per `\n`-terminated line, returns a trailing partial line, and stops at a truncated frame. TTY buffers are one stdout stream. Entries are sorted by the engine's timestamp, stably. `filterLogs(entries, {tail, since})` applies `since` (at or after, millisecond precision) first, then keeps the last `tail` (`tail: 0` returns none).
- `tests/docker-socket.test.ts` (new): the seven socket acceptance lines plus the `nodeSocketProbe` shape.
- `tests/docker-logs.test.ts` (new): multiplexed frames, stream byte 0, split/joined lines, multiple lines per frame, trailing partial lines, truncated frames, time-stable sorting, TTY, and the `filterLogs` lines.
