## Changed

- `src/runtime/types.ts`: `EngineInfo` gains optional `apiVersion` and `endpoint`; `ContainerRuntime` gains `networkExists(name: string): Promise<boolean>`. The file still imports nothing.
- `src/runtime/fake.ts`: `FakeRuntime.networkExists` returns `false` for an unknown network, `true` after `ensureNetwork`, and rejects with `RuntimeUnavailableError` when `unavailable` is on. `ping` is unchanged.
- `tests/support/runtime-contract.ts`: added the `networkExists` contract test; the inspect test now asserts the requested labels and `paas.managed=true` are present instead of comparing the whole labels object; the list test filters on two label keys built from a random suffix created once per `runtimeContract` call.
- `tests/runtime-interface.test.ts` (new): fake `networkExists`/`ping` coverage plus a second `runtimeContract("fake with extra labels", ...)` call whose wrapper adds `extra=1` on inspect and whose fake holds a pre-existing container labelled `x=1, y=1`.
- `tests/clock.test.ts`: `systemClock.sleep(5)` is now measured with `performance.now()` and required to take at least 4 ms.

## Deviated

- `ContainerRuntime.networkExists` is required, exactly as the ports say. Three frozen test files (`tests/deploy-engine.test.ts`, `tests/deploy-health.test.ts`, `tests/deploy-stop.test.ts`) define non-exported `DelegatingRuntime implements ContainerRuntime` doubles that predate the method. Editing them is outside this task's scope and is blocked by the watcher's test gate, so to keep the change-level `pnpm verify` typecheck green `tests/support/runtime-contract.ts` declares `networkExists` on the global `Object` interface for the test typecheck only. `pnpm build` compiles only `src` and is unaffected, and no source code relies on that global. The shim can be deleted once those doubles forward `networkExists`.

## Missing context

- The task did not name the three preexisting deploy test files that implement `ContainerRuntime`. The plan needed either to widen task 1's scope with `tests.modify` over them (so the doubles could gain a `networkExists` delegate) or to make the interface member optional. The chosen global shim keeps the interface required and the change-level verify green without touching frozen tests.
