## Context

Two pure helpers that task 3's adapter and task 4's CLI use. Neither imports dockerode or touches the network; tests inject the filesystem probe and build byte buffers by hand. Reuse `RuntimeUnavailableError` from `src/runtime/errors.ts` and `LogEntry` from `src/runtime/types.ts`, without editing them. No dependency changes; there is no network.

Socket resolution order, from the `Socket resolution` requirement in the `container-runtime` delta:
1. `PAAS_SOCKET`.
2. A `unix://` value of `DOCKER_HOST`, with the scheme stripped. Any other scheme is ignored.
3. `PODMAN_SOCKET`.
4. The first of `/var/run/docker.sock`, `<homedir>/.docker/run/docker.sock`, and `$XDG_RUNTIME_DIR/podman/podman.sock` (or `/run/user/<uid>/podman/podman.sock` when `XDG_RUNTIME_DIR` is unset or empty) for which `probe.exists` is true.

Empty variables count as unset. An explicit setting (1–3) is final:
- If its path exists, return it.
- Otherwise throw `RuntimeUnavailableError` `cannot reach container engine at <path>: socket not found`.

When nothing is found, throw `RuntimeUnavailableError` `no container engine socket found; tried <p1>, <p2>, <p3>; set PAAS_SOCKET`.

The Docker log stream without a TTY is a sequence of frames. Each frame has an 8-byte header: byte 0 is the stream (1 stdout, 2 stderr; treat 0 as stdout), bytes 4–7 are the payload length as a big-endian uint32, and the payload follows. Payload text is UTF-8. Lines end with `\n`, and a line may be split across frames of the same stream. Each line starts with an RFC 3339 timestamp with up to nanoseconds, then one space, then the text. Stop at a truncated frame and ignore the rest. With a TTY, the whole buffer is one stdout stream without headers.

## Ports

```ts
// src/runtime/socket.ts
export interface SocketProbe { exists(path: string): boolean; homedir: string; uid: number }
export type SocketSource = "PAAS_SOCKET" | "DOCKER_HOST" | "PODMAN_SOCKET" | "default";
export interface ResolvedSocket { path: string; source: SocketSource }
export const nodeSocketProbe: SocketProbe; // fs.existsSync, os.homedir(), process.getuid?.() ?? 0
export function resolveSocket(env: NodeJS.ProcessEnv, probe?: SocketProbe): ResolvedSocket; // probe defaults to nodeSocketProbe

// src/runtime/docker-logs.ts
export function demuxDockerLogs(data: Uint8Array, options: { tty: boolean }): LogEntry[]; // entries sorted by time, stable
export function filterLogs(entries: readonly LogEntry[], options: { tail?: number; since?: Date }): LogEntry[]; // since (>=, ms precision) first, then tail
```

## Acceptance
- [ ] With every variable set, `PAAS_SOCKET` wins; without it, `DOCKER_HOST=unix:///a.sock` gives `/a.sock` with source `DOCKER_HOST`; `DOCKER_HOST=tcp://h:2375` is ignored; `PODMAN_SOCKET` comes next; empty values count as unset.
- [ ] An explicit setting whose path the probe says is missing throws `RuntimeUnavailableError` with the exact contracted message, even when `/var/run/docker.sock` exists.
- [ ] Without variables, defaults are probed in order: `/var/run/docker.sock`, then `<homedir>/.docker/run/docker.sock`, then `$XDG_RUNTIME_DIR/podman/podman.sock`, or `/run/user/<uid>/podman/podman.sock` when `XDG_RUNTIME_DIR` is unset; with none existing, it throws the contracted "no container engine socket found" message listing the three paths it tried.
- [ ] `demuxDockerLogs` on a stdout frame `2026-01-01T00:00:00.123456789Z a\n` and a stderr frame `2026-01-01T00:00:01.000000000Z b\n` returns a stdout entry `a` at `2026-01-01T00:00:00.123Z` and a stderr entry `b` at `2026-01-01T00:00:01.000Z`.
- [ ] A line split across two stdout frames becomes one entry; two lines in one frame become two entries; a trailing partial line without `\n` is still returned; a truncated final frame is ignored without throwing.
- [ ] With `tty: true`, a headerless buffer of two timestamped lines gives two stdout entries.
- [ ] `filterLogs` keeps entries at or after `since` to the millisecond, then keeps the last `tail`; with neither it returns every entry; `tail: 0` returns none.
