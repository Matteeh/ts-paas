## Context

Use `DatabaseSync` from `node:sqlite` (Node 24; typed by the installed `@types/node`). It has no transaction helper: run each migration between `BEGIN IMMEDIATE` and `COMMIT`, and `ROLLBACK` then rethrow on error. Foreign keys are on by default; keep them on. Reuse `Clock` and `systemClock` from `src/clock.ts` (do not edit it); tests use `FakeClock` from there. Use `randomBytes` from `node:crypto` for the default id generator. No dependency changes; there is no network.

Tasks 2 and 3 add `src/state/apps.ts` and `src/state/deployments.ts` against this schema and never edit this task's files, so `MIGRATIONS` must hold the whole v1 schema as one migration:
- `schema_migrations(version INTEGER PRIMARY KEY, applied_at TEXT NOT NULL)`, created outside the numbered migrations before any is applied.
- `apps(name TEXT PRIMARY KEY, image TEXT NOT NULL, port INTEGER NOT NULL, hostname TEXT UNIQUE, env TEXT NOT NULL, created_at TEXT NOT NULL, updated_at TEXT NOT NULL)`; `env` is a JSON object.
- `deployments(seq INTEGER PRIMARY KEY AUTOINCREMENT, id TEXT NOT NULL UNIQUE, app TEXT NOT NULL REFERENCES apps(name) ON DELETE CASCADE, image TEXT NOT NULL, status TEXT NOT NULL, container_id TEXT, error TEXT, created_at TEXT NOT NULL, finished_at TEXT)`.
- `deployment_events(seq INTEGER PRIMARY KEY AUTOINCREMENT, deployment_id TEXT NOT NULL REFERENCES deployments(id) ON DELETE CASCADE, status TEXT NOT NULL, at TEXT NOT NULL)`.

Every error class sets `name` to its own class name; set `this.name = new.target.name` in `StateError` so subclasses inherit it. Error messages: `app "<name>" not found`, `app "<name>" already exists`, `hostname "<hostname>" is already used by app "<app>"`, `app "<name>" has a running deployment; stop the app first`, `deployment "<id>" not found`, `deployment "<id>" is already <status>`, and the `SchemaTooNewError` message in the `app-state` delta.

The silent-open test spawns `process.execPath` with `--import tsx` and an `--input-type=module` `--eval` script that imports `src/state/db.ts` by absolute file URL, opens a database in a temporary directory, and closes it.

## Ports

```ts
// src/state/paths.ts
export function paasHome(env?: NodeJS.ProcessEnv): string;   // env defaults to process.env; PAAS_HOME if non-empty, else join(homedir(), ".paas")
export function stateDbPath(env?: NodeJS.ProcessEnv): string; // join(paasHome(env), "state.db")

// src/state/errors.ts
export class StateError extends Error { constructor(message: string) }
export class ValidationError extends StateError { readonly field: string; constructor(field: string, message: string) }
export class AppNotFoundError extends StateError { constructor(name: string) }
export class AppExistsError extends StateError { constructor(name: string) }
export class HostnameInUseError extends StateError { constructor(hostname: string, app: string) }
export class AppRunningError extends StateError { constructor(name: string) }
export class DeploymentNotFoundError extends StateError { constructor(id: string) }
export class DeploymentFinishedError extends StateError { constructor(id: string, status: string) }
export class SchemaTooNewError extends StateError { readonly found: number; readonly supported: number; constructor(found: number, supported: number) }

// src/state/db.ts
import type { DatabaseSync } from "node:sqlite";
import type { Clock } from "../clock.js";
export interface Store {
  readonly db: DatabaseSync;
  readonly clock: Clock;
  newId(): string;
  close(): void;
}
export interface OpenStoreOptions {
  clock?: Clock;                    // default systemClock
  newId?: () => string;             // default 12 random lowercase hex characters
  migrations?: readonly string[];   // default MIGRATIONS; tests pass their own
}
export const MIGRATIONS: readonly string[];  // SQL; migration version = index + 1
export function openStore(path: string, options?: OpenStoreOptions): Store; // ":memory:" or a file path; creates missing parent directories
export function schemaVersion(store: Store): number; // highest recorded version, 0 when none
```

## Acceptance
- [ ] `paasHome` returns `PAAS_HOME` when it is set and non-empty and `join(homedir(), ".paas")` when it is unset or empty; `stateDbPath` appends `state.db`.
- [ ] `openStore(":memory:")` applies `MIGRATIONS`, so `schemaVersion` equals `MIGRATIONS.length`, and the `apps`, `deployments` and `deployment_events` tables exist; the default `newId` returns 12 lowercase hex characters.
- [ ] Opening a file path under a temporary directory whose parents do not exist creates them and the file; after close and reopen, each version appears exactly once in `schema_migrations`, with `applied_at` equal to the injected clock's ISO time.
- [ ] With `migrations` `["CREATE TABLE a(x)", "CREATE TABLE b(y); SELECT * FROM nope"]` on a file database, opening throws, table `a` exists with version 1 recorded, and table `b` does not exist and version 2 is not recorded.
- [ ] After inserting version 99 into `schema_migrations` and closing, reopening throws `SchemaTooNewError` with `found` 99, `supported` `MIGRATIONS.length`, and the message from the delta.
- [ ] Each error class is an `instanceof StateError` and `Error`, has `name` equal to its class name and the message listed in Context; `ValidationError` keeps `field`.
- [ ] A child process that opens and closes a file database through `openStore` exits 0 with empty stderr.
