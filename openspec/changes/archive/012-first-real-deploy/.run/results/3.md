- `tests/e2e/first-deploy.e2e.ts`: new end-to-end file. Without `PAAS_E2E=1` it registers one skipped test named `first real deploy`. The `after` hook removes every `paas.test=e2e` resource in a `finally` around removing the temp `PAAS_HOME`.
