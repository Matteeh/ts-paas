## Context

This task writes the ports only. Task 2 writes `FakeRuntime` and the contract suite against them, so write the signatures below exactly. No dependency changes; there is no network.

Follow the existing style in `src/errors.ts` (`UsageError` sets `name` in its constructor). Relative imports use the `.js` extension. Type-only imports use `import type` (`verbatimModuleSyntax` is on). `src/runtime/types.ts` imports nothing outside `src/`.

`FakeClock.advance` must let work chained on a resolved sleep run before it settles: after resolving each due sleeper, await a macrotask (`setImmediate`) before continuing. Task 2's fake schedules delayed container exits with `clock.sleep(ms).then(...)` and relies on this.

## Ports

```ts
// src/clock.ts
export interface Clock {
  now(): Date;                      // a new Date each call
  sleep(ms: number): Promise<void>; // ms <= 0 resolves immediately
}
export const systemClock: Clock;    // Date and setTimeout
export class FakeClock implements Clock {
  constructor(start?: Date);        // default new Date("2026-01-01T00:00:00.000Z")
  now(): Date;
  sleep(ms: number): Promise<void>; // resolves when advance() reaches now + ms
  advance(ms: number): Promise<void>;
}

// src/runtime/errors.ts
export class RuntimeError extends Error { constructor(message: string, options?: { cause?: unknown }) }
export class ImageNotFoundError extends RuntimeError {}
export class ContainerNotFoundError extends RuntimeError {}
export class NameConflictError extends RuntimeError {}
export class RuntimeUnavailableError extends RuntimeError {}

// src/runtime/types.ts
export const MANAGED_LABEL = "paas.managed";
```

## Acceptance
- [ ] `src/clock.ts`, `src/runtime/errors.ts`, and `src/runtime/types.ts` export exactly the ports above, and `src/runtime/types.ts` imports nothing.
- [ ] `systemClock.now()` is within 1 s of `Date.now()`, and `systemClock.sleep(5)` resolves after at least 5 ms of real time.
- [ ] `new FakeClock().now()` is `2026-01-01T00:00:00.000Z`, `new FakeClock(d).now()` equals `d`, and `now()` stays the same with no `advance`, even after real time passes; mutating a returned Date does not change the clock.
- [ ] On a `FakeClock`, `sleep(3000)` is still pending after `await advance(2999)` and resolved after `await advance(1)`, and `now()` is then start + 3000 ms; `sleep(0)` resolves without `advance`.
- [ ] Two sleeps of 200 ms and 100 ms resolve in due order within a single `advance(500)`, each seeing `now()` equal to its own due time, and a `.then` callback chained on each has run by the time `advance` settles; `now()` is start + 500 ms afterwards.
- [ ] Each of the four error subclasses is an `instanceof RuntimeError` and `Error`, has `name` equal to its class name, keeps the given message, and keeps `cause` when one is given; `tests/runtime-errors.test.ts` also asserts `MANAGED_LABEL === "paas.managed"`.
