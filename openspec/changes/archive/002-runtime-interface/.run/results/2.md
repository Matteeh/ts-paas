# Task 2 result

## Changed

- `src/runtime/fake.ts`: added `FakeImageScript`, `FakeRuntimeOptions`, and `FakeRuntime`, an in-memory `ContainerRuntime`. It pulls/fails images from `pullFailures`, assigns `fake-<n>` ids in creation order, adds `MANAGED_LABEL=true`, tracks the full lifecycle, filters `listContainers` by all labels, applies `since` then `tail` to logs, and makes every operation reject with `RuntimeUnavailableError` when `unavailable` is set. Delayed exits are scheduled with `clock.sleep(exitAfterMs).then(...)` and guarded by a per-start token so a stale delay cannot affect a later start; no `setTimeout` is used.
- `tests/support/runtime-contract.ts`: added `ContractHarness` and `runtimeContract(label, factory)`, which registers one `describe` named `container runtime contract: <label>`. Each test builds a fresh harness from `factory` and calls `teardown` in a `finally`. The suite checks engine info, image pull/presence, idempotent network/volume ensure, create and inspect by id/name, managed label, name conflicts, lifecycle idempotence, forced removal, unknown-container errors, label filtering, and log ordering/`tail`/`since`, using only `ContainerRuntime`.
- `tests/runtime-fake.test.ts`: calls `runtimeContract("fake", ...)` with a `FakeRuntime` whose `pullFailures` holds the harness's missing image, and adds fake-specific tests for `ping`, id assignment order, the managed label, immediate and delayed scripted exits, scripted logs over three starts, and the `unavailable` switch.
