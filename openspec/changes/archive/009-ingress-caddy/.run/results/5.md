## Changed

- `src/commands/context.ts`: added the optional `admin?: () => CaddyAdmin` field to `CommandContext` and exported `getAdmin(context)`, which returns the injected client or a default `HttpCaddyAdmin(DEFAULT_ADMIN_URL)`. All existing exports and behavior are unchanged.
- `src/program.ts`: `buildProgram` options now accept `admin?: () => CaddyAdmin`, pass it into the context, and register the new ingress command group. All existing registrations are unchanged.
- `src/commands/ingress.ts`: new `registerIngressCommand` registering `paas ingress` with `up`, `down` and `status`. `up` parses `--tls`, `--http-port` and `--https-port` (ports through `parsePort`), stores only the flags given, brings ingress up with the injected admin client, and prints the contracted line. `down` prints the removed/absent message. `status` supports `--json` and prints the five labels padded to 10 characters plus one route line each.
- `tests/ingress-cli.test.ts`: new in-process CLI tests covering the bare group help and exit 2, created/unchanged up, flag persistence, invalid values leaving no container and default settings, route count and status output, status without Caddy (human and JSON), and down twice.
