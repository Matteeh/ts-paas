## Context

Contract: "Admin client" in the `ingress` delta.

`HttpCaddyAdmin` in `src/ingress/admin.ts` uses the global `fetch`, which always sends `Sec-Fetch-Mode: cors`. Caddy 2.11.4's admin API checks origins whenever a request has an `Origin` or `Sec-Fetch-Mode` header, and then answers `403 {"error":"client is not allowed to access from origin ''"}`. Replace the private request helper with `request` from `node:http`. Send only the headers the call needs: `Content-Type: application/json` and `Content-Length` for `load`. Pass `agent: false` so that no kept-alive socket outlives a request and holds the CLI open. A request `error` event becomes `AdminUnreachableError`, with `<cause>` taken from the error's `code`, or else its message. A non-2xx status becomes `AdminRequestError` with the first line of the body, as today. `getConfig` returns `null` for an empty body, and the parsed JSON otherwise.

Keep every export, class, message format and the `CaddyAdmin` interface unchanged. `tests/ingress-admin.test.ts` is frozen and must pass unchanged, and so must the other ingress tests that `verify` runs.

In the new `tests/ingress-admin-headers.test.ts`, start a `node:http` server on `127.0.0.1` port 0 that answers exactly as Caddy does, 403 with the body above, when a request has an `origin`, `referer` or any `sec-fetch-*` header, and 200 otherwise. It records each request's header names. Copy the server helper pattern from `tests/ingress-admin.test.ts`; do not import from it. No other network use.

## Acceptance
- [ ] Against the origin-enforcing server, `load(config)` resolves and the server received `POST /load` whose body parses to `config`; `getConfig()` resolves with the JSON the server returned for `GET /config/`.
- [ ] No recorded request carries an `origin`, `referer` or `sec-fetch-*` header, and `load` sends `content-type: application/json`.
- [ ] A server answering 200 with an empty body makes `getConfig()` resolve `null`.
- [ ] A refused port still rejects with `AdminUnreachableError` whose message starts `cannot reach Caddy admin API at http://127.0.0.1:<port>: ECONNREFUSED`.
- [ ] A 400 `{"error":"bad config"}` still rejects with `AdminRequestError`, `status` 400, message `Caddy admin API answered 400: {"error":"bad config"}`.
- [ ] `src/ingress/admin.ts` no longer calls `fetch`, and `tests/ingress-admin.test.ts`, `tests/ingress-caddy.test.ts`, `tests/ingress-cli.test.ts` and `tests/ingress-deploy-cli.test.ts` pass unchanged.
