## Changed

- `src/runtime/errors.ts`: added `PortInUseError extends RuntimeError` with a readonly `address: string | null`, whose constructor takes `(message, address, { cause })` and inherits `name === "PortInUseError"` from the base class.
- `src/runtime/docker.ts`: imported `PortInUseError`; added `isPortInUseMessage` (case-insensitive match for `address already in use`, `port is already allocated`, `ports are not available`) and `portInUseAddress` (first match, in order, of `listen tcp <host>:<port>`, `Bind for <host>:<port>`, `exposing port TCP <host>:<port>`, IPv4 or bracketed IPv6, else `null`). Wired into `mapError` for kinds `create` and `container` (which `startContainer` uses), placed before the create 409 / `already in use` name-conflict rules so it takes precedence.
- `tests/docker-port-in-use.test.ts`: new stub-based tests covering all acceptance lines (start for each of the three recorded messages with the right address, message and cause; create for the Docker Engine message; busy-port message with no address; name-conflict and plain-500 regressions; `PortInUseError` name and `RuntimeError` ancestry).
