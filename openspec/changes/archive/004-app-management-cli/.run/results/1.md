## Changed

- Added `src/commands/context.ts` with `CommandContext`, `withStore` (opens `stateDbPath(context.env)` once and closes in `finally`), `failUsage` (via `command.error("error: …", { exitCode: 2, code: "paas.usage" })`), and `runAction` (maps `ValidationError`/`UsageError` to `failUsage`, rethrows everything else).
- Added `src/commands/format.ts` with `MASK`, `AppView`, `toAppView` (status from the latest deployment, env values masked unless `reveal`), `formatAppDetails` (9-char padded labels, sorted env, `-` fallbacks), `formatTable` (left-aligned, two-space columns, no trailing spaces), `parseEnvPairs` (split at first `=`, later wins, usage error on missing `=`/empty key), `parsePort` (digits only), and `collect`.
- Added `tests/commands-helpers.test.ts` covering every acceptance line: store open/return/close on success and failure, persistence across calls, usage-vs-operation error handling through `run`, view/detail formatting, table formatting, and the parser helpers.
